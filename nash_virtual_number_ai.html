Good to know

Frequently asked questions

Can I receive SMS immediately on this website?

Not yet. The site needs an integrated telecom provider, a backend endpoint and a provisioned number that supports the required message type. This starter does not receive SMS.

Can I use virtual numbers for verification?

Use numbers only for accounts and services you are authorized to access. Some platforms prohibit VoIP or shared numbers and some providers do not support one-time passcodes. Check both sets of terms. This service is not intended to bypass security, identity checks, rate limits or platform rules.

Does sign-up work?

The form currently validates input and shows a setup notice. It does not create a persistent account. Production authentication must be handled by a secure identity provider or backend, with passwords never stored in browser storage.

Can customers pay online?

Checkout buttons are placeholders. Connect a payment processor using server-created checkout sessions and verified webhooks. Never put secret payment keys in this HTML file.

Can GitHub host the website?

GitHub Pages can host a static prototype subject to GitHub's current terms and restrictions. A commercial SaaS service may need a separate hosting provider for its production frontend and backend. Check the current policy before launch.

How will NASH earn revenue?

Possible revenue streams include clearly disclosed subscriptions, business communication tools and service fees where permitted by provider contracts. Model telecom costs, support, taxes, payment fees and refunds before setting final prices.
